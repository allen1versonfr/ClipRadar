# antislop audit 002 (2026-11-05): the running app

Mode: after. Direction: `DESIGN.md`. Done on 4.42.1 (PR #66).

How: the real server with a generated 2-minute project (analysed, one clip kept and rendered). I went through
Home, Review (picker and editor), Exports (empty and with a rendered clip) and every Settings section at
1366 × 860 and at 390 × 844. Accent use was measured from computed styles, and overflow was measured
element by element.

Already fine: no console errors on any screen. Icon-only buttons (×, ▶, −, +) have accessible names.
Empty and loading states exist on every screen. Pending titles are in italics on purpose (they're still
being written).

## Requested separately: remove the previous UI

The React UI has been the default since 4.25.0, and the previous page is only reachable through
"Previous UI". Plan:

- Delete `src/ui/index.html`, `app.js` and `app.css`. Keep `src/ui/fonts/` and the icons, which the
  React UI and the renderer use.
- Server: remove `/legacy/` and `CLIPRADAR_UI=legacy`. With no React build, `/` explains how to build it
  instead of falling back to the old page.
- React UI: remove the "Previous UI" button in the top bar, the block in Settings › About and its search
  words.
- Startup self-check (`app.py`): check the bundled fonts instead of the old page.
- Tests: delete `tests/test_ui.py` and the old-page steps in 8 other tests (compare-with-old-page checks,
  `/legacy/` routes). Remove the CI steps that ran the old page.
- `scripts/api_routes.py` and `docs/api-routes.md`: only the React sources.
- Docs that describe the present (`DESIGN.md`, `docs/user-guide.txt`) stop mentioning the old page.
  Past audits and the changelog stay as they were written.
