Twitch sign-in

          
Twitch puts ads into live streams for viewers without Turbo. VodClipper spots those ad breaks and leaves them out of recordings either way. Sign in with an account that has Turbo (or a sub to the channel) and Twitch sends the ad-free stream instead, so recording never pauses for an ad.

          

            
            
            
          

          

            Paste a sign-in token instead
            
On twitch.tv, signed in, press F12, open Application › Cookies › https://www.twitch.tv and copy the value of auth-token. It's stored encrypted for your Windows account and only sent to Twitch. Also used for subscriber-only VODs.

            

          

        


        

          
Clip ranking

          
VodClipper learns from the clips you keep, skip and post, separately for each streamer, and moves moments like the ones you pick up the list. It starts after about 8 decisions.

          

            

            

          

        


        

          
Live clipping

          
          
Works from any window while live clipping is running, so you can keep watching the stream or playing. You'll hear a short sound when the clip is taken.

            Private repository 
            
If VodClipper's GitHub repository is private, updates need a read-only access token. On GitHub: Settings › Developer settings › Fine-grained tokens › Generate.
